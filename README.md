# Pedro Chaves - Portfolio

Modern and clean personal portfolio and CV for Pedro Chaves, showcasing GitHub projects and professional experience.

## Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS 4.0
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Build Tool**: Vite

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
